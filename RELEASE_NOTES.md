First installable version.

- Scan from the Canon imageCLASS MF635Cx over the network (eSCL) or with the Windows driver (WIA)
- Flatbed / document feeder / double-sided, Color / Grayscale / B&W, up to 600 DPI (1200 enhanced)
- Each scan is its own job; merge jobs when you want
- Zoom (Ctrl+wheel, 100% / 200%) and scroll through pages
- Crop, rotate 90°, straighten by any angle, enlarge / shrink, undo and reset
- Save as PDF, JPG or PNG
- Built-in "Update" button when a new version is released
